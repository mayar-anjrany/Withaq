# موقع وثاق (Withaq)

موقع تعريفي ثابت بالكامل: HTML + CSS + جافاسكربت صرفة، بدون أي أدوات بناء أو مكتبات.
كل الأكواد غير مضغوطة ومعلّقة بالعربية، والخطوط مستضافة داخل المشروع.

## النشر على Vercel
1. ارفع المجلد كاملًا إلى مستودع GitHub، أو اسحبه إلى Vercel.
2. اختر Framework Preset: **Other** واترك أمر البناء ومجلد الإخراج فارغين.
3. ملف `vercel.json` يفعّل الروابط النظيفة (`/about` بدل `about.html`) وترويسات الأمان.

بعد النشر بنطاقك الفعلي:
- استبدل `YOUR-DOMAIN.com` في `sitemap.xml` و`robots.txt`.
- إن أردت صورة المشاركة تعمل في واتساب وتويتر، اجعل مسار `og:image` مطلقًا (يبدأ بـ https://نطاقك).

## بيانات الشركة (مكان واحد)
افتح `assets/js/site-config.js` واملأ: الاسم القانوني، الاختصاص القضائي، البريد، تاريخ آخر تحديث، حسابات التواصل.
أي حقل فارغ يظهر في الموقع كـ [قيد التعبئة] بخلفية رمادية، وعند تعبئته يظهر في كل الصفحات.
رقم واتساب الحالي: +963 968 236 616.

لإخفاء لافتة «مسودة قيد المراجعة القانونية» بعد مراجعة المستشار: `showLegalDraftBanner: false`.

## هيكل المشروع
```
index.html … 404.html        الصفحات (17 صفحة)
assets/css/fonts.css         تعريف الخطوط
assets/css/base.css          الألوان والأحجام (المتغيرات) والتخطيط
assets/css/components.css    الأزرار والبطاقات والرأس والتذييل والنماذج
assets/css/pages.css         أنماط الصفحات
assets/js/site-config.js     بيانات الشركة
assets/js/main.js            القائمة + تعبئة البيانات + نماذج واتساب
assets/fonts/                Noto Kufi Arabic · Readex Pro · Manrope (مع تراخيصها)
assets/img/                  الشعار والأيقونات وصورة المشاركة
vercel.json · sitemap.xml · robots.txt · manifest.webmanifest
```

## كيف تعدّل
- **الألوان والأحجام:** أعلى `assets/css/base.css` (المتغيرات من دليل الهوية).
- **نص صفحة:** افتح ملفها وعدّل داخل `<main>`.
- **القائمة والتذييل:** مكرران في كل صفحة (لأن الموقع ثابت بلا أدوات بناء). عدّلهما بالبحث والاستبدال في كل الملفات.
- **أنماط مضمّنة:** تجنّب `style="…"` داخل HTML لأن سياسة الأمان CSP في `vercel.json` تمنعها. أضف صنفًا في CSS بدلًا منها.
- **أدوات خارجية (تحليلات مثلًا):** تحتاج تعديل `Content-Security-Policy` في `vercel.json` وتحديث «سياسة ملفات الارتباط».

## النماذج
نموذجا «اطلب عرضًا تجريبيًا» و«تواصل معنا» يبنيان رسالة ويفتحان واتساب على الرقم أعلاه. لا يُخزَّن شيء على الموقع ولا يوجد خادم.

## قواعد الهوية المطبّقة
- ألوان: حبر الليل `#1F2A44`، طين `#C8745A` (للتمييز فقط، نحو 5%)، رمل `#F5EFE6`، ضباب `#8FA6C1`، حجر `#E4DDD2`.
- الأخضر للحضور وتأكيد الحفظ فقط، والأحمر للأخطاء والغياب فقط.
- العناوين Noto Kufi Arabic 700، النصوص Readex Pro، الأرقام والحروف اللاتينية Manrope، والأرقام لاتينية (0-9).
- نص أساسي 17/1.8، أدنى 14، طول سطر ≤ 62 حرفًا، زوايا 12px، أيقونات بسماكة 1.75 على شبكة 24px.
- لا أسعار ولا أرقام مالية ولا أرقام عملاء في الموقع.

## قبل الإطلاق
- راجع الصفحات القانونية الست مع مستشار (مسودات وفق مبادئ دولية، وفيها أقواس [..] تحتاج قرارًا).
- أكمل بيانات الشركة، وحدّد مزوّد الاستضافة وأعلنه في الخصوصية والأسئلة الشائعة.
- لا يحتوي الموقع على صفحة فريق أو صور فوتوغرافية. أضفها عند توفرها.
