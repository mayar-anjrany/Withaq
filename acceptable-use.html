سياسة الاستخدام المقبول

نحمي المنصة ومستخدميها بقواعد بسيطة وواضحة.

مسودة قيد المراجعة القانونية. هذه الصفحة مكتوبة وفق مبادئ حماية البيانات المعترف بها دوليًا في الصحة الرقمية، لكنها ليست استشارة قانونية، ولم تُعتمد بعد. لا تعتمد عليها قبل مراجعتها مع مستشار قانوني مرخّص.

المسموح

  • استخدام المنصة لإدارة عيادة أو مركز نفسي بصورة مشروعة.
  • إدخال بيانات المراجعين بالقدر اللازم للرعاية وبموافقة من يلزم موافقته.

غير المسموح

  • محاولة الوصول إلى بيانات لا صلاحية لك عليها، أو مشاركة بيانات الدخول.
  • تعطيل المنصة أو اختراقها أو اختبارها دون إذن مكتوب.
  • رفع محتوى غير قانوني أو برمجيات خبيثة.
  • استخدام المنصة لإرسال رسائل مزعجة أو إعلانية للمراجعين.
  • استخدام بيانات المراجعين لغير الغرض المهني الذي جُمعت له.
  • انتحال صفة أو ممارسة المهنة دون ترخيص.
  • إعادة بيع الخدمة أو تقديمها لطرف آخر دون اتفاق.

الإبلاغ

إن لاحظت إساءة استخدام أو ثغرة أمنية، راسلنا عبر صفحة التواصل واختر «أمان (بلاغ)».

الإجراءات

قد نحذّر أو نعلّق أو ننهي الحساب عند المخالفة، وقد نبلّغ الجهات المختصة إذا اقتضى القانون ذلك.
